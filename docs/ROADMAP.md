# 사용자에게 더 유용한 정보를 주기 위한 방안

작성 기준: 2026-10-31, 보조금24 데이터 10,942건 실측. 숫자는 `pipeline/build/full.json` 을 직접 센 값이다.

## 원칙
1. **정확성이 먼저다.** 공공데이터에 없는 것을 지어내지 않는다. 읽어 내기 애매한 값(금액, 날짜)은 뽑지 않거나 원문을 그대로 보여준다.
2. **"내게 해당하는가"에 답한다.** 목록을 늘리는 것보다 "왜 이게 나왔는지, 지금 뭘 하면 되는지"를 보여준다.
3. **광고·후기·커뮤니티는 지금 하지 않는다.** 신뢰와 모더레이션 부담이 크고, 이 서비스의 강점(공식 데이터)과 맞지 않는다.

## 제안 (우선순위순)

| # | 제안 | 사용자 가치 | 작업량* | 위험 |
|---|---|---|---|---|
| A | **시군구 선택** (시·도 → 시군구). 선택하면 내 시군구 + 광역 + 중앙 정책만, "시·도 전체" 선택도 가능 | 매우 큼. 엉뚱한 지역 정책 제거 | 2 | 낮음 (데이터 100% 분리 가능) |
| B | **"왜 나왔나" 표시.** 카드에 일치한 조건을 칩으로: `서울 · 임산부 · 중위소득 50% 이하` / 확인이 안 된 조건은 "나이 확인 필요" | 큼. 신뢰와 판단 속도 | 1 | 낮음 |
| C | **같은 이름 정책 묶기.** 내 지역 것을 먼저 보여주고 "다른 지역 N곳"으로 접기 | 큼. 목록 20% 정리 | 2 | 중간 (이름이 같아도 내용이 다를 수 있어 묶음 안에서 지역 표기 필수) |
| D | **한눈에 보기 칩.** 지원유형(현금·현물·이용권·서비스), 신청 방식(온라인·방문·불필요), 지원내용 속 금액 문구를 **원문 그대로 발췌**(읽기 확실한 경우만). "온라인 신청 가능" 필터 | 큼. 클릭 전에 판단 가능 | 2 | 중간 (금액을 숫자로 변환하지 않고 원문 발췌만) |
| E | **신청 준비 카드.** 필요한 서류를 체크리스트(기기에 저장), 전화 걸기 버튼, 접수기관 | 중간. 신청까지 이어짐 | 1 | 낮음 |
| F | **저장과 공유.** 관심 지원 저장(기기), 내 조건을 주소로 공유(개인정보는 주소에 넣지 않고 구간·선택값만), 마감일은 달력(.ics) 추가 | 중간. 재방문·확산 | 2 | 낮음 (주소에 이메일·정확한 소득 넣지 않기) |
| G | **알림 확장.** 주간 요약: 신규 + 마감 임박 + 내 저장 정책 변경 | 중간 | 1 | 도메인과 메일 설정 선행 필요 |
| H | **신뢰 장치.** "정보가 다른가요?" 신고 링크(공식 페이지로 안내 + 메일), 데이터 기준일·출처 상단 표기 | 중간. 오류 피드백 확보 | 0.5 | 낮음 |

*작업량 = 하루 2시간 세션 수 기준 대략치(구현·테스트·배포 포함).

### 하지 않는 것
- **금액 총합이나 "연 ○○만원 받을 수 있어요" 같은 계산**: 중복 수급·자격 조건을 무시한 숫자라 오해를 부른다.
- **핫딜·후기·커뮤니티**: 이 서비스의 신뢰 포지션과 충돌하고 운영 부담이 크다.
- **LLM 요약으로 자격을 판정**: 틀린 안내의 책임이 크다. 요약을 쓰더라도 원문을 함께 보이고 "참고용"으로만.

## 실행 순서

1. **1주차**: A(시군구) → B(일치 이유) → H(신뢰 장치). 같은 데이터·화면을 건드려서 함께 하는 편이 효율적이다.
2. **2주차**: C(묶기) → D(한눈에 칩) → E(신청 준비 카드).
3. **3주차 이후**: F(저장·공유), 도메인이 생기면 G(주간 알림).

각 단계는 배포 후 방문 통계(Cloudflare Web Analytics)에서 아래를 본다.
- 정책 페이지 조회 수와 메인 페이지 대비 비율(상세로 넘어가는 정도)
- 재방문 비율(저장·공유 도입 효과)
- 사용자 오류 신고 건수(정확성 지표)

Web Analytics 는 버튼 클릭 같은 이벤트를 세지 못한다. "공식 페이지 클릭 수"가 필요해지면 개인정보를 받지 않는 간단한 카운터(Cloudflare Worker)를 따로 둔다.

## 이미 반영한 것 (이 문서 작성 시점)
- 신청 기간이 끝난 지원 숨김 + 마감 임박(D-day)·접수 예정 표시 + 마감 임박순 정렬 + 알림에서 마감 건 제외
  (날짜를 확실히 읽을 수 있는 687건에만 적용, 반복·상시·애매한 표현은 숨기지 않음)
- 출생연도·소득 계산기, 구비서류·온라인 신청·근거 법령, 분야 썸네일, 공유 미리보기
